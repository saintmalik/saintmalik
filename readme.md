## Site content

Edit these JSON files (no HTML edits needed for new entries):

- `assets/talks.json` — talks page (newest first; undated at the end)
- `assets/projects.json` — projects page + home featured list (`"featured": true`)
- `assets/oss.json` — open-source contribution snapshot (refresh separately)

Then run `bash build.sh` (copies into `output/` for Cloudflare Pages).
